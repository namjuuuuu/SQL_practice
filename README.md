## 학습 내용

- SELECT / WHERE
- GROUP BY / HAVING
- JOIN
- Subquery
- CASE
- NULL 처리

추후 IT 감사에서 필요한 데이터 조회 및 통제 테스트에 활용하는 것을 목표로 합니다.
